# 🗄️ Exercícios de Banco de Dados MySQL

Este repositório contém as atividades práticas desenvolvidas durante o curso da **Generation Brasil**, focadas na criação e manipulação de bancos de dados relacionais utilizando **MySQL**.

## 📋 Projetos Incluídos

O repositório está organizado em três scripts principais, cada um resolvendo um cenário de negócio diferente:

1.  **RH (Recursos Humanos):** Criação de um sistema para gerenciar colaboradores, cargos e salários.
2.  **E-commerce:** Estrutura de banco de dados para controle de estoque de produtos e categorias.
3.  **Escola:** Sistema para gestão de registros de estudantes, notas e informações acadêmicas.

## 🚀 Tecnologias Utilizadas

* **MySQL**: Banco de dados relacional.
* **Git & GitHub**: Controle de versão e hospedagem do código.

## 🛠️ Como executar os scripts

Para testar os scripts localmente, você pode:
1. Clonar este repositório.
2. Abrir o **MySQL Workbench** ou terminal do MySQL.
3. Copiar o conteúdo dos arquivos `.sql` e executar no seu servidor local.
